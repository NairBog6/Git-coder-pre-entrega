# Proyecto Base - Diplomatura Git y GitHub

##  Descripción 
Este repositorio contiene la estructura base e infraestructura de gestión para el desarrollo del proyecto de la diplomatura. El objetivo de esta etapa es establecer un flujo de trabajo profesional utilizando Git y GitHub.

##  Tecnologías Utilizadas
* **Git:** Control de versiones local.
* **GitHub:** Alojamiento del repositorio remoto.
* **Markdown:** Documentación del proyecto.

##  Contenido del Repositorio
* `.gitignore`: Filtro para evitar subir archivos innecesarios o sensibles.
* `README.md`: Documentación e instrucciones del proyecto.
