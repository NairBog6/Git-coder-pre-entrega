# Proyecto Base - Diplomatura Git y GitHub
## Descripción
Este repositorio contiene la estructura base, documentación y flujo colaborativo desarrollados durante la diplomatura. El objetivo principal es consolidar buenas prácticas de versionado y trabajo en equipo profesional utilizando Git y GitHub.
## Tecnologías Utilizadas
* **Git:** Control de versiones distribuido.
* **GitHub:** Alojamiento remoto, gestión de ramas, Issues y Pull Requests.
* **Markdown:** Documentación estructurada del proyecto.
## Contenido del Repositorio
* `.gitignore`: Filtro configurado para evitar el seguimiento de archivos temporales del sistema y del editor.
* `README.md`: Documentación completa, especificaciones técnicas y guía de colaboración.
## Flujo de Trabajo Colaborativo
Para el desarrollo y evolución del proyecto se implementó un flujo de trabajo profesional basado en:
* **Feature Branching:** Cada nueva característica o mejora se desarrolla en una rama aislada (`feature/` o `docs/`), evitando modificaciones directas sobre la rama `main`.
* **Gestión de Issues:** Seguimiento y organización de tareas y requerimientos mediante la pestaña de Issues en GitHub.
* **Pull Requests (PR):** Revisión e integración de cambios a la rama principal a través de PRs documentados y mergeados tras su validación.
